`main.py` (Python 3.13, stdlib only) writes one sentence to
`/output/entry.txt`:

> This meeting has no decision, no owner, and no end — just a calendar invite with witnesses.

## Why this line

A pointless meeting is defined by what it lacks: no decision gets made,
nobody owns the outcome, and it never really ends. The punchline reframes
the attendees as witnesses — the meeting was a non-event with an audience.

## Run

```sh
python3 main.py
```
